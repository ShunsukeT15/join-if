## 無料利用枠について

- Lambda・CloudFront・CloudWatch Logs の無料枠は「常時無料」のため、アカウント作成時期にかかわらず適用されます。
- RDS の無料枠はアカウント作成時期で異なります。
  - 2025-07-15 より前に作成したアカウント: 作成から12か月間、db.t4g.micro 750時間/月と 20GB が無料（期間内なら RDS も実質 0 円）。
  - それ以降に作成したアカウント: 無料プランのクレジット（最大 200 USD・6か月）から差し引き。
- このアカウントの適用状況は Billing コンソールの「無料利用枠」で確認してください。

## さらに安くする選択肢

| 方法 | 月額の目安 | トレードオフ |
| --- | --- | --- |
| 使わない期間は RDS を停止 | 停止中はストレージ分のみ（約 2.8） | 停止は最大7日で自動起動するため運用の手間 |
| Aurora Serverless v2（0 ACU まで縮退） | アイドル時 数 USD | 再開時に十数秒の遅延 |
| DynamoDB アダプタを追加 | ほぼ 0 | 永続化アダプタの追加実装が必要（ポート設計上は差し替え可能） |
| DB だけ Supabase 無料枠 | 0 | DB が AWS 外になる |

## 費用の監視

`npm run setup:aws -- --budget-email <アドレス> --budget-usd <金額>` で、月額予算の**予測または実績が予算額を超えたとき**にメール通知する AWS Budgets を作成します（現在の設定: 15 USD）。
コスト配分タグ `Project` を Billing コンソールで有効化すると、このプロジェクト分だけを絞り込めます。
